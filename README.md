# Vibecoded-Pokedex
Most of the pokedex websites out there are "good enough" but lack some features, mainly the ability to view the shiny forms and alternate forms of pokemon, or if they do show it, the website looks like it was made in 2001 (bulbapedia). So, this is just a simple pokedex, looks clean, and it's easy to use.
